# Google Play checklist

- [ ] Re-check Developer Program Policies, target API, User Data, Families, billing, and account-deletion rules
- [ ] Generated project compiles/targets API 36 or newer current requirement
- [ ] Inspect signed AAB, native `.so` 16 KB compatibility, permissions, SDKs, endpoints, and signing certificate
- [ ] Confirm package ownership, versionCode monotonicity, Play App Signing, and protected upload key
- [ ] Reconcile Data Safety form with inventory, production SDKs/processors, encryption, and deletion
- [ ] Verify in-app and external web account deletion
- [ ] Complete UGC moderation, report/block, policy, and operations review
- [ ] Complete App Access, content rating, target audience, ads, category, support/privacy URLs, metadata, screenshots
- [ ] Approve billing path for any digital product before it appears in the app
- [ ] Verify App Links and deployed `assetlinks.json` with the production app-signing fingerprint
- [ ] Upload explicitly to an internal/closed track before a separately approved production rollout
