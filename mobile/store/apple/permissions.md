# Apple permissions

The generated Info.plist declares camera, selected photo library, and location-when-in-use with French purpose strings describing listing publication. Face ID, microphone, motion, and always/background location purpose strings are deliberately absent. Notifications are requested at runtime only after user-facing context.

Test first request, denial, limited photo access, settings recovery, and repeated use on supported iPhone/iPad versions. Manual location entry and continuing without camera access must remain usable. Any capability addition requires config, inventory, privacy-policy, App Privacy, test, and review-note updates before release.
