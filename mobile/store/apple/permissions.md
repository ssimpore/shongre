# Apple permissions

The generated Info.plist declares only selected photo-library access, with a French purpose string describing listing publication. Camera, Face ID, microphone, motion, and location purpose strings are deliberately absent. Notifications are requested at runtime only after user-facing context.

Test first request, denial, limited photo access, settings recovery, and repeated use on supported iPhone/iPad versions. Manual location entry and continuing without photo access must remain usable. Any capability addition requires config, inventory, privacy-policy, App Privacy, test, and review-note updates before release.
