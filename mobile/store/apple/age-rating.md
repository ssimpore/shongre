# Apple age rating notes

Shongre contains user-generated classifieds, seller/buyer messaging, commerce, location descriptions, and report/block tools. It is not designed for children, but the final questionnaire must be answered from the live category inventory, moderation policy, ads (none today), contests, gambling, medical content, violence, sexual content, and unrestricted web access.

Product/legal owners must complete the current App Store Connect questionnaire, set any market/category restrictions, and ensure store copy and parental-age statements match the result. No rating is asserted in this repository.
