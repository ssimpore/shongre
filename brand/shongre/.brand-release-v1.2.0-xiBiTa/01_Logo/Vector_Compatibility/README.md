# Vector compatibility

The SVG files in this folder are self-contained wrappers around the approved
high-resolution PNG artwork. They scale cleanly in browsers and common design
tools while preserving the exact approved appearance.

They do not contain editable Bezier paths. For trademark masters, signage,
embroidery, engraving, vehicle graphics, or very large output, commission a
manual vector redraw and compare it carefully against the PNG master before
replacing these files.
