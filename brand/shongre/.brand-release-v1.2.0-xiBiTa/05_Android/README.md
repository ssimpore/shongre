# Android assets

Copy the contents of `app/src/main/res` into the corresponding Android resource
folders. The package includes:

- Legacy launcher icons from mdpi through xxxhdpi.
- Adaptive icon XML under `mipmap-anydpi-v26`.
- A 108 x 108 dp orange background layer.
- A transparent foreground layer with the critical monogram inside the central
  66 x 66 dp safe zone.
- A monochrome layer for themed icons.
- Google Play icon and feature graphic under `play-store/`.

Preview circle, squircle, rounded-square, and platform-specific masks before
release.
