# Web assets

- `favicon/`: multi-size ICO plus transparent PNG favicons.
- `apple-touch-icon.png`: 180 x 180 home-screen shortcut icon.
- `pwa/`: 192 and 512 px standard and maskable icons.
- `site.webmanifest`: starter manifest referencing the included PWA icons.
- `header/`: transparent horizontal logos at 240, 480, and 960 px widths.
- `open-graph/`: 1200 x 630 share images on light and dark backgrounds.

Prefer PNG for transparent UI artwork and WebP for lightweight static delivery.
Keep the SVG compatibility note in `01_Logo/Vector_Compatibility` in mind for
large reproduction.
